# Pulse

A simple local video and audio player. Open files from your device — nothing is uploaded.

## Features

- Video and audio in one playlist
- Drag and drop, multi-file open, folder import
- Play, pause, seek, skip, next / previous
- Volume, mute, speed, repeat, shuffle
- Fullscreen and picture-in-picture
- Audio visualizer and 3-band equalizer
- Video fit, rotate, mirror, brightness / contrast / saturation
- Subtitles (VTT / SRT)
- A–B loop and sleep timer
- Keyboard shortcuts
- Remembers volume, speed, and playback position
- Works offline after load

## Run

```bash
npm install
npm run dev
```

Open the URL Vite prints, then drop media files or use **Open**.

## Shortcuts

| Key | Action |
| --- | --- |
| Space / K | Play / pause |
| J / L | Skip back / forward |
| ← / → | Skip 5 seconds |
| ↑ / ↓ | Volume |
| M | Mute |
| F | Fullscreen |
| I | Picture in picture |
| N / P | Next / previous |
| [ / ] | Speed |
| 0–9 | Jump through the file |
| ? | Settings |
